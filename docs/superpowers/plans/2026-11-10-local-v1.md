# Local V1 Implementation Plan

> Agent workflow: executing-plans, TDD, direct commits/push to main as explicitly requested.

**Goal:** local working SVG illustration composer covering R01–R15.
**Architecture:** versioned SVG assets + Pydantic scene, FastAPI exports, React SVG editor.
**Stack:** Python 3.12, FastAPI, PostgreSQL/SQLAlchemy/Alembic, React/TypeScript/Vite.
**Spec:** ../../PROPOSAL.md and ../../RESEARCH.md, approved in chat.

## Global constraints

Only original vector geometry, true S/L variants, original relative sizes,
palette roles enforced, editable standalone SVG, no public secrets.
OpenAI only selects catalog IDs; inexpensive configurable gpt-5.4-nano default.
No paid requests until local credentials are available. Preserve offline mode explicitly.

## Review focus

- Duplicate instance SVG IDs and broken mask/gradient references: exporter regression.
- Palette swaps accumulate errors or leak object colors to background: matrix regression.
- Session isolation and concurrent project saves: API integration regression.
- Reload or stale request overwrites edits: browser and state regression.
- Invalid/refused/timeout AI response: transport fakes, preserved scene and visible errors.

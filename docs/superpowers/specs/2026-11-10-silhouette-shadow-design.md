# Проекция силуэта вместо растянутой исходной тени

Пользователь 10 ноября изменил желаемый эффект: копия самого предмета чёрного цвета,
адаптированная к плоскости опоры, с закреплёнными точками контакта. Это разрешение
заменяет прежнее требование работать только с исходным отпечатком. Исходники не меняем.
Обычный режим остаётся исходной иллюстрацией; новый эффект действует только при «Своей тени».

## Выбранный подход

Проецируем точный SVG-силуэт отделённого предмета аффинным сдвигом относительно линии
опоры. Точки на линии остаются неподвижными, поперечный масштаб сохраняется. Направление
и длина определяют наклон проекции, а не поворот всей чёрной копии. Под предметом
проекция маскируется его непрозрачным телом; исходная тень в этом режиме скрыта.
Просветы сохраняются. Никакой сетки соединяющих треугольников, повторных растровых изображений
или внешних зависимостей в экспорте. Это управляемая 2D-проекция, не реконструкция 3D.

Отвергнутые варианты: прежняя растяжка отпечатка не узнаваема; свободная чёрная копия
отрывается от основания; 3D-реконструкция не нужна для данного векторного редактора.

## Контракт

Метаданные добавляют projection: { ground: [x1,y1,x2,y2], depth: number,
body_bbox: [x,y,width,height] }. Линия проходит через видимое нижнее ребро опоры тела; для монеты и вазы — внутри
площади круглой опоры. Касательная в единственной нижней точке отвергнута после
визуальной проверки: создавала эффект парения. Один выбранный элемент опоры семейства
масштабируется в отдельно измеренные границы тела S/L и ролей, чтобы он не перескакивал.
Направление angle — по часовой стрелке от правого направления, default 90°; length —
относительная длина проекции. x/y в прежних сохранениях адаптируются к вектору проекции,
никогда не сдвигают опору. scale_x/y не растягивают ширину силуэта.

На холсте можно выбрать видимую тень и потянуть её/рамку: изменяется вектор проекции,
основание остаётся на месте. Поворотная ручка вращает направление вокруг контакта,
изменение длины сохраняет поперечную ширину. Удаление эффекта возвращает исходный SVG.

## Приёмка

- Все 40 вариантов, несколько направлений и длин, вращение/масштаб владельца.
- Фиксированные контактные точки, чёрный силуэт, просветы, тело выше любой тени.
- Нет прежнего отпечатка одновременно с новым, нет чёрных треугольников/сетки.
- Непрозрачное основание закрывает тень; сохраняется preview/export parity.
- Сохранение/отмена/повтор/экспорт/перезагрузка и обычный режим не регрессируют.
- Визуальный лист десяти семейств; проверка в браузере и Linux CI.

# Художественная компоновка обычного редактора

> Архив этапа разработки. Текущее принятое поведение описано в [итоге V1](../../V1.md);
> при выпуске использовать [актуальную инструкцию](../../DEPLOYMENT.md).

Пользователь разрешил доработку: крупность, кадрирование, фоновые роли и цвета,
натуральное падение исходных теней на нижние поверхности. Алгоритм должен работать
на новых запросах без таблиц координат примеров. Эксперимент и production пока не менять.

## Решение

Выбран семантический план + геометрические ограничения + общий кадр. LLM передаёт
только семьи, отношения и ограниченный словарь художественных указаний. Буквальные
указания пользователя имеют приоритет. Численные позы рассчитываются локально.
Фиксированные координаты/шаблоны сочетаний предметов исключены; выдача произвольных
координат моделью не даёт воспроизводимых ограничений и не используется.

- ArtDirection: framing fit/close/bleed, focus, роли, названия цветов, край кадра.
  Компонентный режим принимает те же указания без платного вызова.
- Ограничения pack остаются обязательными. Для художественной сцены проверяются
  несколько геометрических кандидатов с разным порядком/аспектом упаковки, затем
  камера выбирает общий масштаб и смещение. Индивидуальные пропорции не меняются.
- Обычный fit сохраняет прежнюю безопасную сборку. Close/bleed допускают обрезку
  больших предметов; маленькие предметы и контактные группы должны оставаться
  читаемыми. Полное исчезновение выбранного предмета запрещено, есть fallback fit.
- Роль background меняет реальный исходник и выбирает только фоновые цвета.
  Персональная color_map связывает роли исходной палитры с ролями текущей палитры;
  маски не перекрашиваются, контуры/штрихи не заменяются одной заливкой.
- Scene v1 дополнен framing и color_map с безопасными defaults. Сохранение,
  JSON, смена размера/палитры, галерея, preview и SVG сохраняют результат.
- Обычная исходная тень верхнего слоя принимается фактической альфой видимых тел
  ниже. Для явной опоры прежнее contact-only поведение сохраняется, чтобы не было
  тени в воздухе. При отсутствии опоры сохраняется пол, видимые поверхности
  получают перекрывающий участок. Источник света и собственная проекция остаются экспериментом.

## Проверка

Сохранить старые отрицательные сравнения. Добавить художественные описания 18 примеров
и отдельный набор новых сочетаний, перефразировок, S/L, всех форматов и палитр.
Измерять роли/цвета/крупность/видимость/кадрирование/отношения и различие вариантов,
а не называть совпадение bounding boxes физически верной тенью. Тени проверять
нативными пикселями: принимающая поверхность, просветы, верхний слой, фон и экспорт.
Контуры/хеши всех 40 оригиналов неизменны. Финальный полный прогон после заморозки,
один Playwright runner; реальные LLM-вызовы только для итоговой интеграции через прокси.

# Опциональный режим «Своя тень»

> Архив этапа разработки. Текущее принятое поведение описано в [итоге V1](../../V1.md);
> при выпуске использовать [актуальную инструкцию](../../DEPLOYMENT.md).

Пользователь одобрил отдельную микрофункцию 10 ноября 2026. Исходный вид и основной
сценарий сохраняются по умолчанию. Включение относится только к выбранному экземпляру.

Варианты: дополнительная SVG drop-shadow даёт двойную тень и зависит от фильтров;
замена исходной тени в копии позволяет управлять ею без изменения файлов библиотеки.
Выбран второй вариант. Точная разметка исходных теневых контуров хранится в каталоге,
не определяется по цвету во время работы. Существующие исходники и path data неизменны.

Новая тень строится как плоская проекция маски предмета и поворачивается вокруг
опорной точки под предметом, остаётся векторной отдельной группой. Параметры экземпляра:
направление 0–360°, длина 0–200% условного размера проекции и непрозрачность 0–100%. Это художественная
настройка существующего плоского рисунка, не физическое освещение/перерисовка предмета.
Свет/внутренние блики остаются исходными. При выключении исходный SVG восстанавливается.

Параметры входят в Scene JSON с необязательным полем shadow: старые проекты валидны,
мigrations таблиц не нужны. Undo/redo, duplicate, роли, S/L, save/reload, JSON и SVG
сохраняют настройки. Preview и Python export используют одну разметку и формулу.
Управление доступно в отдельной секции инспектора, заблокированный объект не меняется.

Приёмка: визуальная сверка всех 40 вариантов, тесты неизменности стандартного режима,
разметки/валидации/преобразования/палитры/ссылок и Playwright полного пользовательского пути.

Решение после исследования: тень слита с подмалёвком и обводкой, поэтому отдельного
готового контура недостаточно. Используются проверенные маски тела и контактная точка
на реальном предмете; для монеты производная дуга замыкает боковую стенку. Это только
дополнительный режим. Цена решения: художественная аппроксимация при отделении слитых
участков; физическое переосвещение исходной иллюстрации не обещается.

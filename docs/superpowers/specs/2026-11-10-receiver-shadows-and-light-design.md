# Тени на опорах и экспериментальный источник света

> Архив этапа разработки. Текущее принятое поведение описано в [итоге V1](../../V1.md);
> при выпуске использовать [актуальную инструкцию](../../DEPLOYMENT.md).

Пользователь просит исправить цепочку «лампа стоит на телефоне и на лампе лежит
ручка»: тень ручки должна попадать на лампу, а основания лампы — на телефон.
Эта возможность остаётся основной при полном отключении экспериментальных теней.
Отдельно пробуем управление источником света, похожее по взаимодействию на Blender.
Исходные SVG содержат 2D-рисунок; свет управляет тенями, исходные блики не перестраиваются.

## Основной проход приёмников

Element.support_ids: list[str] = [] хранит ID экземпляров опор для явных отношений on.
Несколько опор сохраняются без потери; позади/спереди сами по себе опорой не являются.
Проверяем ссылки, уникальность, отсутствие самоссылок и циклов. Порядок стабильно
топологический: опоры перед предметами. Ручная смена порядка отсоединяет пересечённые
связи. Перемещение сохраняет связь; тень рисуется только в реальном пересечении с опорой.
Удаление очищает ссылки; копирование и вставка сохраняют только существующие опоры.

Нижний проход теней сохраняется. Перед телом каждого предмета рисуется его тень,
обрезанная фактической векторной альфой тел опор (без их теней и контактных слоёв).
Порядок цепочки: phone.body → lamp.shadow∩phone.body → lamp.body → pen.shadow∩lamp.body → pen.body.
Никаких теней поверх несвязанных предметов. Скрытая опора не принимает тень.
Оригинальная тень работает при выключенном эксперименте; активный свет использует
согласованную с ним проекцию и на полу, и на опорах. Превью и экспорт совпадают.
В настройках предмета можно назначить/убрать опору вручную.

## Экспериментальный свет

Scene.light: null | {enabled: bool, x: finite, y: finite, height: finite, opacity: finite}.
x/y ограничены ±5000; height 50–5000 (default 1000); opacity 0–1 (default .35).
Перетаскиваемая метка источника на холсте, настройка высоты и плотности тени.
При первом включении UI выбирает высоту max(1000, 1.5×большая сторона холста),
не более 5000, чтобы начальный свет не давал чрезмерно длинные тени на story.
Глобальный свет управляет всеми предметами; индивидуальное управление тенями в этом
режиме скрыто. Выключение общего света возвращает сохранённые индивидуальные настройки.

Псевдовысота предмета H = projection.depth × scene.scale × owner.scale_y.
От мировой точки опоры A луч к полу даёт вектор (A-light.xy)*H/max(light.height-H,20).
Переводим в локальную систему владельца, вычисляем angle и length, ограничиваем 0–200%.
Пропорции и закреплённая опора сохраняются. Это управляемая SVG-проекция, не 3D-рендер.
Один жест — один undo; поддерживаются отмена жеста, сохранение, reload и экспорт.

CUSTOM_SHADOWS_ENABLED=true (default) — серверный master-флаг всех экспериментальных
теней. Bootstrap.features.custom_shadows сообщает его фронту. При false отсутствуют
своя тень, общий свет, ручки/метка/горячие клавиши для теней; рендер и экспорт используют
обычные тени. Сохранённые настройки не удаляются. Основные тени на опорах остаются.
Изменение env применяется перезапуском сервиса и обновлением страницы.

## Приёмка

Точный запрос пользователя и похожие цепочки во всех трёх вариантах; ручное назначение
опоры; S/L, роли, поворот/растяжение, отверстия, несколько опор, скрытие, удаление,
порядок, clipboard, undo/redo, сохранение/reload. Pixel parity preview/export.
Свет слева/справа/высоко/низко меняет проекции; метка не экспортируется.
При master=false контактные тени остаются, динамические настройки и эффекты исчезают.
Нет платных AI-вызовов в диагностике; оригинальные файлы не меняются.

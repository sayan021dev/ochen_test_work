# Source artwork

The two `originals/library-*.svg` files are unchanged SVG exports of the supplied
Figma assignment sections `21:25788` (L) and `21:25859` (S), with IDs enabled.
Source: https://www.figma.com/design/dnuDZosHkN6ajkhiVfavRw/

`source-map.json` records the original node IDs and dimensions read from Figma.
`library/` and `catalog.json` are reproducibly extracted by `scripts/import_catalog.py`.
The script preserves path data and includes two loose book contours from the source.

Artwork is supplied solely as assignment material; no additional licence or ownership
of this artwork is claimed. Any code licence does not apply to the source artwork.

18 примеров Figma: проверка без подмены результата

Первый столбец — исходный пример. Второй — диагностический перенос найденных координат в нашу Scene и настоящий renderer, а не результат генерации. Столбцы 3–5 — настоящий compose_variants с вводом списка предметов. Шестой — лучший из трёх результатов по пространственному описанию. Оба алгоритмических набора проверяются без LLM и координат эталона. Кадрирование и фоновые роли проверяются отдельно; пиксельное совпадение не обещается.
